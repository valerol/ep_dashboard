# Экземпляры циклов

Каждый файл `<cycle_instance_id>.yaml` содержит ровно один фактический `CYCLE_RECORD`.

Папка намеренно не содержит примеров: файл в этом каталоге считается утверждением о состоянии проекта. Для новой записи используйте `../templates/cycle.yaml`, назначьте ID по `EP-DP-DR-006` и зафиксируйте решение `OWNER_LPR` в `source_refs`.
