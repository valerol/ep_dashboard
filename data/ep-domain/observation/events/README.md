# События циклов

Фактические события сохраняются по пути `<YYYY>/<MM>/<observation_event_id>.yaml`, одно событие на файл.

События append-only. Исправление не перезаписывает исходный файл: создаётся новое событие с типом `SUPERSEDE` или `TOMBSTONE`, ссылкой на исправляемую запись и причиной.

Для новой записи используйте `../templates/event.yaml`.
