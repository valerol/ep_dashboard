# Источники и конфиденциальность

Репозиторий публичный, поэтому здесь не хранятся оригиналы договоров, финансовых файлов, этикеток, выгрузок, переписок и других закрытых материалов.

Безопасный реестр находится в `data/source-registry.json`. Он содержит только устойчивый идентификатор, тип, статус и краткую область подтверждения. Оригиналы остаются в приватном рабочем хранилище проекта.

При проверке факта следует сопоставить `sourceIds` записи сайта с оригиналом в приватном хранилище. Реестр не заменяет исходный документ и не расширяет объём подтверждённых сведений.
