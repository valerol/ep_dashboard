# Elephant Pants — философская машина

Макет главной страницы проекта Elephant Pants, подготовленный по рукописной схеме от 5 августа 2026 года и последующему уточнению её структуры.

## Семантика модели

- `Economics` — верхнеуровневый повторяющийся цикл.
- `Import`, `Logistic`, `Sales` — три вложенных цикла.
- `ChinRada`, `CDEK`, `Self`, `Ozon` — узлы взаимодействия, а не отдельные циклы.
- `Logistic` подразделяется на `CDEK` и `Self`.
- `Opers` — единая операционная таблица. Для каждого oper следующим шагом должна быть добавлена детальная инструкция.
- `catalog` — входной поток, `cashflow` — выходной поток, `budget` — обратный контур следующего оборота.
- Декларация 3Д, настройка маркировки и брендирование — отдельные разовые циклы, а не четвёртый цикл `Economics`.

## Запуск

```bash
npm ci
npm run dev
```

Производственная сборка:

```bash
npm run build
```

## Файлы

- `index.html` — самостоятельный адаптивный макет со стилями и интерактивной подсветкой циклов.
- `vite.config.js` — конфигурация локального просмотра и сборки.
- `package.json` и `package-lock.json` — воспроизводимое окружение проекта.

Опубликованный сайт этим репозиторием автоматически не изменяется. Перенос макета на сайт выполняется отдельным действием в ChatGPT Work.
