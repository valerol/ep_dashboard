# Elephant Pants

Исходники рабочего представления проекта Elephant Pants: философская машина, дорожная карта, текущий шаг, новости и история изменений.

## Принцип обновления

Интерфейс отделён от подтверждённых данных. Новые промпты и документы сначала проходят проверку источника, после чего изменяется только соответствующий файл в `data/`.

- неподтверждённые сведения не становятся фактами;
- `action`, `oper` и `cycle_closed` не взаимозаменяемы;
- бизнес-события отделены от истории сайта;
- закрытые документы не добавляются в публичный репозиторий;
- каждая содержательная запись ссылается на безопасный `sourceId`.

Полный порядок: [`prompts/UPDATE_SITE.md`](prompts/UPDATE_SITE.md).

## Структура

- `app/` — интерфейс и стили;
- `data/roadmap.json` — долгосрочные этапы;
- `data/current-step.json` — текущие задачи;
- `data/news.json` — бизнес-события;
- `data/organs.json` — функциональные органы проекта;
- `data/machine.json` — циклы, узлы и opers;
- `data/ep-domain/` — канонический доменный namespace;
- `data/ep-domain/domain-physiology/CURRENT.md` — указатель на текущую доменную физиологию;
- `data/ep-domain/repository-map.yaml` — машиночитаемая карта доменной структуры;
- `data/site-changelog.json` — история представления сайта;
- `data/source-registry.json` — обезличенный реестр подтверждений и пробелов;
- `sources/` — правила обращения с приватными первоисточниками;
- `tests/` — проверки отображения и целостности связей;
- `build/`, `worker/`, `scripts/` — сборка и публикация через Sites.

## Локальная проверка

Требуется Node.js `>=22.13.0`.

```bash
npm ci
npm run lint
npm test
```

В Linux-среде Sites сборка ограничена по времени через GNU `timeout`. На macOS тот же скрипт автоматически запускает сборку без внешнего ограничения времени.

## Публикация

`.openai/hosting.json` связывает проект с существующим сайтом Sites. Секреты и реальные документы в репозитории не хранятся.

## Проекция циклов в Google Calendar

Датированные циклы с `schedule.calendar_publish: true` автоматически отражаются в календаре `Elephant Pants`. Канонический источник — только `data/ep-domain/observation/cycles`; обратная синхронизация из Google Calendar запрещена.

Локальная проверка без доступа к календарю:

```bash
npm run sync:calendar:dry-run
npm run test:calendar-sync
```

GitHub Actions запускает синхронизацию после изменений циклов и ежедневно в 08:00 `Asia/Vladivostok`. Для активации нужны Repository Secrets:

- `GOOGLE_CALENDAR_ID` — идентификатор календаря `Elephant Pants`;
- `GOOGLE_CALENDAR_SERVICE_ACCOUNT_JSON` — JSON ключ сервисного аккаунта Google Cloud с включённым Calendar API.

Календарь `Elephant Pants` должен быть предоставлен адресу `client_email` из ключа с правом изменения событий. Секреты и идентификатор календаря не добавляются в файлы репозитория.

Напоминания Google Calendar являются настройкой конкретного пользователя. Сервисный аккаунт публикует запрошенный интервал в описании события, а само событие использует стандартные уведомления календаря. Поэтому каждому пользователю, которому нужны уведомления, следует задать для календаря `Elephant Pants` стандартное уведомление за сутки.
